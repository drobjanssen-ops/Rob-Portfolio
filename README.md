# Rob Janssen Mejico — IT Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Included sections
- About
- Skills
- Selected Projects (Escapar and SE1 & SE2 Research)
- Contact

## Run locally
Open `index.html` in a web browser.

## Deploy with GitHub Pages
1. Create a public GitHub repository (for example, `it-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` directly to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.
